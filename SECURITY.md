# Security Policy

## Supported Version

Security fixes are applied to the latest commit on `main`. Open Prospector is a local-first,
single-user application and is not designed for remote hosting or untrusted users.

## Reporting A Vulnerability

Use [GitHub private vulnerability reporting](https://github.com/olewandowski1/open-local-prospector/security/advisories/new)
for vulnerabilities involving private-network access, untrusted source content, local file access,
provider credentials, or another trust boundary.

Include the affected version or commit, operating system, reproduction steps, and expected impact.
Do not include real business data, provider credentials, or private workspace files.

Please allow a reasonable period for investigation before publishing details. Ordinary bugs and
feature requests can use the public issue tracker.
