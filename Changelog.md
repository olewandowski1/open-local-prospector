# Changelog

## 0.0.1 - 2026-08-23

### Added

- Local-first business discovery, website inspection, evidence collection, and candidate review.
- Support for Claude, Codex, and OpenCode clients installed and authenticated on the local computer.
- Durable, resumable runs backed by a local SQLite workspace.
- Dark mode documentation screenshots and Open Prospector branding.

### Changed

- Established `0.0.1` as the initial project version.
